# Laravel + Bash + Python Integration Lab

A beginner-level practical project to understand how different technologies work together as one system.

This project is separate from my core knowledge study.

I will use the things I already know and learn through **building, testing, breaking, and debugging**.

---

## 🎯 Goal

Build a small system:

```text
Client
  ↓
Laravel API
  ↓
Bash
  ↓
Python
  ↓
Laravel Response
```

The first version will run **locally**.

After the local version works and I understand the data flow, I will containerize it with Docker.

Later, I will modify the architecture and introduce database-driven processing.

---

## 📅 Roadmap

### — Local Integration

```text
Laravel → Bash → Python → Laravel
```

Focus:

* API
* Process execution
* Arguments
* JSON
* Bash orchestration
* Error handling

###  — Docker

Containerize the working local system.

Focus:

* Images
* Containers
* Dockerfile
* Docker Compose
* Networking
* Volumes

### — Database

Introduce database persistence.

Focus:

* Database connection
* Migration
* Data flow
* Persistence
* Environment variables

### — Break & Debug

Intentionally break the system and troubleshoot it.

Focus:

* Logs
* Errors
* Process failures
* Network failures
* Database failures
* Debugging methodology

## 🧠 Brain Digest

I will not research everything before building.

My approach:

```text
Build
 ↓
Encounter a problem/question
 ↓
Think
 ↓
Investigate
 ↓
Understand

 ↓

```

The purpose is to understand **what each component does and why it is needed**, not just to make the project work.
